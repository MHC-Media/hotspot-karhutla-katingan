Memuat data ISPU…

Kategori ISPU (Kementerian LHK): 0–50 Baik · 51–100 Sedang · 101–200 Tidak Sehat · 201–300 Sangat Tidak Sehat · di atas 300 Berbahaya. Nilai ISPU adalah sub-indeks tertinggi dari parameter yang tersedia (parameter dominan) menurut Permen LHK No. 14 Tahun 2020 (PM10, PM2.5, SO₂: rata-rata 24 jam; CO dan O₃: 8 jam; NO₂: 1 jam). HC tidak tersedia pada model CAMS (±40 km), jadi nilai ini estimasi model dan dapat berbeda dari stasiun pemantau DLH.

Sumber Data

Asal data yang ditampilkan pada dashboard ini, beserta cakupan dan frekuensi pembaruannya.

NASA FIRMS

Titik panas (hotspot) dari satelit VIIRS (SNPP, NOAA-20, NOAA-21) dan MODIS (Terra/Aqua), data near real-time. Diambil otomatis oleh server lalu difilter ke wilayah Katingan.

VIIRS 375 m · MODIS 1 kmTarikan terakhir: -
firms.modaps.eosdis.nasa.gov

BMKG

Prakiraan cuaca per desa/kelurahan (suhu, kelembapan, curah hujan, tutupan awan, angin) dari API publik BMKG.

Per desa/kelurahanDiperbarui berkala
data.bmkg.go.id

Open-Meteo

Data angin ketinggian 10 m untuk animasi aliran angin, panah angin, dan proyeksi arah penjalaran api pada titik panas.

Angin 10 mCadangan: prakiraan angin BMKG
open-meteo.com

Copernicus CAMS

PM10, PM2.5, SO₂, CO, O₃, dan NO₂ per desa/kelurahan dari model kualitas udara global CAMS (Copernicus) via Open-Meteo Air Quality API dengan cell_selection=nearest (nilai diambil dari sel grid model terdekat dengan titik tengah tiap desa/kelurahan), lalu dikonversi menjadi indeks ISPU (Permen LHK No. 14/2020). HC tidak tersedia; acuan resmi tetap stasiun pemantau DLH.

±40 km · per jamISPU dari 6 parameterDiperbarui: -
atmosphere.copernicus.eu

ISPU Kabupaten Katingan

Kartu ISPU Kab. Katingan di atas peta menampilkan nilai ISPU tertinggi dari seluruh desa/kelurahan beserta nama desa/kelurahan dan kecamatannya. Saat diklik, rincian memuat konsentrasi di lokasi tertinggi tersebut dan rata-rata konsentrasi se-kabupaten. ISPU = sub-indeks tertinggi dari 6 parameter CAMS (Permen LHK No. 14/2020); estimasi model, bukan stasiun DLH.

Catatan penggunaan. Titik panas adalah deteksi anomali panas oleh satelit dan belum tentu kebakaran; konfirmasi lapangan tetap diperlukan. PM2.5 adalah estimasi model (bukan sensor lokal) dan data ISPA bergantung pada kelengkapan input petugas. Gunakan dashboard ini sebagai alat bantu pemantauan, bukan satu-satunya dasar pengambilan keputusan.
